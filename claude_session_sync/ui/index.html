Claude Session Sync

Automatic sync

Needs your attention

What it does

  1. You work in Claude Desktop under one account. When you quit Claude Desktop, the background watcher notices (Desktop must be closed because it rewrites its own files while it runs).
  2. A few seconds later it makes each account's Code tab list the same sessions: it adds/updates a small record in the other account that points at the same conversation file. Nothing is copied or edited in the conversation itself.
  3. Every run takes a full backup first, checks every file it wrote, and undoes itself if anything looks wrong.
  4. Later you open Claude Desktop, sign in with the other account, and continue the same session.

Only Claude Desktop Code-tab sessions are handled. Conversations you ran only in the claude terminal, and Cowork, are never touched. Sessions you deleted in an account are not brought back.

Storage model
